# Contributing

Thank you for your interest in contributing to Trade.

## Project Goals

Trade is an open-source platform for AI-assisted trading research, strategy review, workflow automation, and reproducible analysis.

Contributions are welcome in the following areas:

- Backend services
- Frontend and user experience
- Market data ingestion
- Strategy and rule evaluation
- Documentation
- Testing and quality assurance
- Security review and hardening

## Development Setup

1. Clone the repository.
2. Install project dependencies.
3. Configure a development profile.
4. Start backend and frontend services.
5. Run tests before submitting changes.

Project-specific setup instructions may evolve as the Web-first architecture continues to mature.

## Pull Requests

Please:

- Keep changes focused and easy to review
- Include documentation updates when appropriate
- Avoid unrelated refactoring in feature-specific pull requests
- Ensure tests pass before submission

## Issues

When reporting issues, please include:

- Expected behavior
- Actual behavior
- Steps to reproduce
- Relevant logs or screenshots

## Security

Please do not publicly disclose security vulnerabilities before maintainers have an opportunity to review and address them.

## Code of Conduct

Be respectful, constructive, and collaborative.
