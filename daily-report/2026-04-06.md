1. **export_task.py**：异步增量导出 articles + metadata 到 DuckDB
   - 支持 force_full 全量导出
   - DuckDB 表结构：articles(20列) + metadata(12列)

   - 失败写入 failed_tasks.jsonl
   - Pipeline DAG：`crawl → clean → validate → store → process → export`

3. **Pipeline DAG 集成**：
   - `crawl → clean → validate → store → export` 端到端链路完成
   - `PipelineRunResult` 新增 `export: ExportResult` 字段
