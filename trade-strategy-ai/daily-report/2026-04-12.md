## 实现内容

### 1. pipeline-step 独立步骤命令
- **新增命令**：`python -m cli.main pipeline-step <step>`
- 支持单独执行 crawl/clean/validate/store/process/export
- **自动查找前置文件**：依赖缺失时友好报错
- 支持 `--force` 强制覆盖、`--use-db` 数据库模式
- **代码**：`cli/main.py`

### 2. 正文提取优化
- **问题**：正文包含不必要的干扰内容
- **修复**：优先使用 `.article-text.p_coten#first` 精确标签
- **回退逻辑**：`.p_wenz` → `.p_coten` → `body`
- **代码**：`src/agents/data_agent/sites/tgb.py`

### 3. 评论抓取改为作者评论页
- **新 URL**：`https://www.tgb.cn/topic/lookUserTopic?topicID={topicID}&lookUserID={author_id}`
- **topicID 提取**：从文章 HTML `<input name="topicID" value='...'>` 获取
- **效果**：只抓取该作者本人的评论，不再抓取读者评论
- **代码**：`tgb.py` + `crawl_blog.py`

### 4. 评论页数可配置
- **参数**：`TgbCrawler.max_comment_pages`
- 默认 `None` = 抓取全部，`N` = 最多 N 页
- **代码**：`src/agents/data_agent/sites/tgb.py`

### 5. 跳过纯图片评论
- **过滤规则**：新增 `image_only` 标记
- 空评论（无文字内容）被标记为 `image_only`
- **代码**：`src/agents/data_agent/skills/crawl_blog.py`

### 6. 评论分页抓取（重大修复）
- **问题1**：`comment_id` 每页重新编号（`reply_10461311_1`），第2页被误判为重复 → 修复：改用内层 `.comment-data-text` 的全局唯一 id
- **问题2**：`session_scope` 只在退出时 commit，中断导致数据丢失 → 修复：每篇 article 立即 `session.commit()`
- **问题3**：`topic/lookUserTopic` 服务器忽略 `pageNo` 参数 → 修复：改用文章页 `full_html` + 分页 URL `https://www.tgb.cn/a/{id}-{pageNo}`
- **新增字段**：`quote_text`（被引用内容）、`published_at`、`comment_id`
- **新增方法**：`parse_author_comments_from_article_html`、`_detect_article_total_pages`
- **总页数提取**：`<span>共<b>X</b>/Y页</span>`
- **数据验证**：单篇文章 179 条评论（10页），时间 2026-04-06 至 2026-04-12
