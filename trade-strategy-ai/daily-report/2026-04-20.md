## 实现内容

### 1. KaipanProvider 多域名抓取层
- `src/providers/kaipan_provider.py` 实现 13 个接口的 HTTP 请求
- 支持 3 个 baseURL（`apphis` / `applhb` / `apphwshhq`）
- Raw JSON 保存时内嵌 `meta` 元信息（dataset、trade_date、slot、fetched_at、source、request）
- `_fetch_and_save()` 通用方法减少重复代码，文件名含 `api_name` + 关键参数避免覆盖
- 支持 GET 和 POST 两种 HTTP 方法

### 2. KaipanNormalizer 标准化转换层
- `src/providers/kaipan_normalizer.py` 读取 YAML schema 执行字段映射
- 4 个 schema 文件：`hot_topics.yaml`、`topic_constituents.yaml`、`strong_symbols.yaml`、`market_context.yaml`
- `_get_nested()` 路径解析（支持 `.` 分隔和 `[N]` 数组索引）
- `_transform()` 数组遍历（支持 `[i]` 占位替换）
- `normalize_date()` 批量转换支持任意 slot 配置

### 3. 配置与目录结构
- `config/app.yaml` 添加 `kaipan` 配置节（data_dir、schema_dir、fetch_schedule、trading_calendar）
- `data/kaipan/raw/` 和 `data/kaipan/snapshots/` 目录骨架
- 目录格式：`{dataset}/{trade_date}_{slot}/{dataset}.json`

### 4. 离线验证测试
- `tests/providers/test_kaipan_pipeline.py` 11 个测试全部 PASS
- 覆盖：schema 文件存在性、YAML 合法性、Provider 属性/方法签名、Normalizer 方法存在性、目录结构、配置文件内容
