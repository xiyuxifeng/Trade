完成 Stage 2 两个关键任务：FallbackProvider（NTL-S2-007）和 MarketUniverse Schema（NTL-S2-008）。Provider 层级联降级能力和候选池数据结构契约均已落地。

## 实现内容

### 1. FallbackProvider 完成
- 新增 `src/providers/fallback_provider.py`
- FallbackProvider 继承 `ProviderBase`，维护 `capability -> 有序 provider 列表` 映射
- 支持三种降级场景：
  - 单个 provider 成功 → 直接返回 ok
  - 部分成功（至少一个返回 partial）→ 返回 partial 与聚合错误列表
  - 全部失败 → 返回 partial 与完整错误列表
- 已注册到 `src/providers/__init__.py`

### 2. MarketUniverse Schema 完成
- 新增 `src/market_universe/schemas.py`
- 定义原子 dataclass：
  - `HotTopic` - 热点主题
  - `TopicConstituent` - 题材成分
  - `StrongSymbol` - 强势标的
- 定义聚合 dataclass：
  - `HotTopicsPayload`
  - `TopicConstituentsPayload`
  - `StrongSymbolsPayload`
  - `MarketUniverse` - 顶层聚合
- 与 provider normalize 输出结构完全对齐
- 使用 frozen=True 确保不可变性
