## 实现内容

### 1. NTL-S4-001: TraderAgent 输入重构

- 新增 `strategy_version: StrategyVersion | None` 参数，支持从策略版本派生候选标的
- 新增 `market_universe: MarketUniverse | None` 参数，支持从候选池快照获取强势评分上下文
- 新增 `_candidates_from_strategy()` 私有方法：从 `recommendations` 提取 buy/hold/sell 标的
- 新增 `_strong_symbol_hint()` 私有方法：从 `market_universe.strong_symbols` 提取强势评分提示
- Phase 0 兼容：未传入 `strategy_version` 时降级到原有 watchlist + profile 路径
- TradeIdea 新增 `strategy_version_id` 字段

### 2. NTL-S4-002: buy/sell/hold 三类决策支持

- 移除 `_candidates_from_strategy` 中对 `sell` 决策的过滤
- 现在 buy/hold/sell 三类决策均从 `strategy_version.recommendations` 原样输出
- `TradeIdea.side` 字段正确反映各标的决策类型

### 3. NTL-S4-003: StrategyAgent 版本化规则快照

- `StrategyVersion` 新增 `rules_snapshot: list[dict]` 字段，存储评估规则快照
- `generate_raw_signal` 新增 `strategy_version` 参数
- 规则来源判断：Stage 4 路径使用 `strategy_version.rules_snapshot`，Phase 0 路径使用显式传入的 rules 参数
- context 新增 `strategy_version_id` 字段

### 4. NTL-S4-004: 信号类型上下文扩展

- `SignalContext` 新增 `strategy_version_id`、`market_universe_snapshot`、`topic_source_ids` 字段
- `Signal` 新增 `strategy_version_id` 字段

### 5. NTL-S4-005: signal_version 持久化完整上下文

- `_signal_to_dict` / `_dict_to_signal` 新增 `strategy_version_id` 序列化
- `_context_to_dict` / `_dict_to_context` 新增 `strategy_version_id`、`market_universe_snapshot`、`topic_source_ids` 序列化
- 信号版本化能重放完整盘前上下文

### 6. NTL-S4-006: ManagerAgent 重构接入策略版本与候选池快照

- 新增 `StrategyLibraryService` + `SnapshotService` 依赖
- `run_pre_market` 重构：MarketUniverse 所有 trader 共享，StrategyVersion 每个 trader 独立加载
- `_record_ideas_as_signals` 更新：`Signal.side` 使用 `idea.side`，SignalContext 新增版本/快照/主题追溯字段
- Phase 0 兼容：DB 或快照不可用时自动降级

### 7. NTL-S4-007: 定向深挖 DataRequest 规划

- 新增 `_plan_data_requests()` 方法，从 `rules_snapshot` 条件中提取字段并映射到 DataAgent dataset
- 字段映射：rsi/macd/bollinger/atr/kdj/cci/obv → indicators；close/open/high/low/volume/turnover → ohlcv_1d
- 当 `strategy_version` 存在且有 `rules_snapshot` 时，自动发起 indicators/ohlcv_1d 等额外取数
- `run_pre_market` 集成定向深挖逻辑

### 8. NTL-S4-008: 盘前输出增加策略版本和证据追踪字段

- `TradeIdea` 新增 `source_recommendation_idx: int | None` 字段（来源 recommendation 索引）
- `DailyReport` 新增 `strategy_version_ids: list[str]` 字段（报告级版本追溯）
- `run_pre_market` 收集 `used_strategy_version_ids` 并传入 `DailyReport`

### 9. NTL-S4-009: 下线旧 watchlist + last_price 主路径地位

- 新增 `Stage4Config` 配置类：`enable: bool = True`、`market_universe_slot: str`、`allow_phase0_fallback: bool = True`
- `run_pre_market` 受 `stage4.enable` 控制
- `allow_phase0_fallback=False` 时，strategy_version 不可用则跳过 trader 而非降级

### 10. NTL-S4-010: 拆分 ManagerAgent 中膨胀的编排逻辑

- 新增 `src/agents/manager_agent/premarket_service.py`（`PreMarketService`）
- 将 per-trader 编排逻辑（策略版本加载/定向深挖/信号评估/missing symbols）提取到 `PreMarketService.run_for_trader()`
- `run_pre_market` 简化为循环调用 service
- Manager 只保留编排，不承担具体业务逻辑

### 11. NTL-S4-011: 盘前链路回归测试

- 覆盖：Stage 4 路径候选来自 recommendations 而非 watchlist、Phase 0 降级、allow_phase0_fallback=False 跳过逻辑、DailyReport.strategy_version_ids 追溯、TradeIdea.side 正确传递策略决策
