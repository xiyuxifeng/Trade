## 一句话目标

为 CLI 项目升级 Web 管理后台制定生产级开发计划，并落地 Web 专项任务清单。

## 关键决策

- Web 方案采用标准 Web 管理后台，不做终端 TUI 或简单 CLI 套壳。
- 后端采用 FastAPI UI API/BFF，前端采用 React + TypeScript + Vite。
- CLI 背后的业务逻辑需要抽成 Python service，CLI 和 Web API 共用同一套 service。
- Web 不允许执行任意 shell 字符串；所有操作通过受控 service、Job 和白名单任务执行。
- v1 Job 技术路线确定为：数据库持久化 Job + 独立 Worker 进程 + 数据库轮询锁；暂不强制 Redis/RQ/Celery。
- Web 生产交付必须包含 UserManual 覆盖矩阵、生产级 Job、RBAC、配置安全、E2E 验收和部署/备份/回滚文档。
