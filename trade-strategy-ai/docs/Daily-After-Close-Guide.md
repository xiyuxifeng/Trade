# 每日盘后说明

本文档说明普通用户每天收盘后如何使用 `每日交易` → `今日盘后`。

## 盘后目标

你要完成“计划、实际、原因、改进”的闭环：

- 查看今日信号是否触发。
- 查看实际结果和风险表现。
- 理解成功、失败、未触发、数据不足和冲突原因。
- 处理规则、作者画像和策略优化建议。

## 操作步骤

1. 进入 `每日交易` → `今日盘后`。
2. 检查收盘数据和盘后数据是否就绪。
3. 点击 `生成盘后复盘`。
4. 查看信号结果、结构化归因和市场状态变化。
5. 分别处理规则优化建议、作者画像修订建议和策略修订建议。

## 系统会做什么

系统会按以下顺序处理：

```text
读取今日盘前计划
→ 读取收盘后实际数据
→ 计算信号结果
→ 生成结构化归因
→ 生成三类优化建议
```

系统不会用单日结果直接覆盖正式规则、作者画像或策略。

## 输出结果

盘后完成后，你会看到：

- 今日复盘状态。
- 每个信号的触发和结果。
- 成功、失败和未触发原因。
- 数据不足、无效、冲突或降级说明。
- 规则优化建议。
- 作者画像修订建议。
- 策略修订建议。

## 建议处理方式

### 规则优化建议

你可以：

- 接受为规则草稿。
- 继续观察。
- 拒绝。

注意：

- 接受为草稿不等于直接发布正式规则。
- 草稿仍需审核、回测和适用性确认。

### 作者画像修订建议

你可以：

- 接受为画像修订草稿。
- 继续观察。
- 拒绝。

注意：

- 作者画像描述的是文章表达、规则结构和回测观察。
- 不能把它理解为作者真实实盘表现。

### 策略修订建议

你可以：

- 接受为策略草稿。
- 继续观察。
- 拒绝。

注意：

- 策略草稿需要重新验证和人工发布。
- 当前正式策略不会因为一天的结果自动改变。

## 状态处理

### 数据不足

影响：

- 某些信号无法完整计算结果。
- 建议只能作为观察线索。

你应该做什么：

- 先补齐数据。
- 补齐后重新生成盘后复盘。

### 部分可用

影响：

- 系统只复盘可确认的信号和实际数据。

你应该做什么：

- 查看哪些信号受影响。
- 对受影响建议选择继续观察。

### 无效

影响：

- 输入数据或计划状态不满足复盘条件。

你应该做什么：

- 按页面说明修复计划或数据状态。
- 不要把无效复盘当成成功。

### 冲突

影响：

- 多个证据版本不一致，系统无法给出可信结论。

你应该做什么：

- 联系管理员检查数据版本和审计记录。
- 冲突解除后重新生成复盘。

## 下一步

- 明天盘前继续进入 `每日交易` → `今日盘前`。
- 累计多日证据后，再考虑发布新的规则、画像或策略版本。
