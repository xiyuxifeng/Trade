# 产品使用流程与页面说明

## 1. 文档目的

这份文档只回答一个问题：用户打开 Web 端后，应该怎么一步一步使用这个系统。

它不解释内部实现细节，不讨论数据库表，不讨论 Job 分层，不讨论具体抓取逻辑。它只关注：

- 用户从哪里开始。
- 每一步在做什么。
- 每一步输入什么。
- 每一步输出什么。
- 最终能得到什么结果。

## 2. 产品目标

这个项目要帮助用户完成一条连续的分析链路：

```text
博客文章
  -> 规则提取
  -> 回测验证
  -> 交易员画像
  -> 盘前预测
  -> 盘后复盘
```

用户不应该先理解 `MarketUniverse`、`Market Snapshot`、`snapshot-build` 这些内部名词，才能开始使用系统。

## 3. Web 首页应该先告诉用户什么

用户进入 Web 后，首页应该先回答三个问题：

1. 我现在能做什么。
2. 我应该先看哪里。
3. 我做完之后会得到什么。

### 首页建议展示的入口

1. 文章与规则
   - 导入文章，查看规则抽取结果
2. 回测与画像
   - 验证规则可信度，沉淀交易员风格
3. 盘前分析
   - 结合当天市场背景生成盘前建议
4. 盘后复盘
   - 对照盘前结果检查当天判断
5. 市场上下文
   - 查看当天市场状态和背景

市场上下文可以作为辅助入口存在，但不应抢占主流程位置。

## 4. 主流程说明

### Step 1. 导入博客文章

作用：

- 把交易员博客文章作为原始输入。
- 为规则提取提供数据来源。

用户能得到什么：

- 文章进入系统。
- 可以查看处理状态。
- 可以看到失败原因。

### Step 2. 提取规则

作用：

- 把文章中的自然语言内容转成结构化规则。
- 形成后续回测可用的规则对象。

用户能得到什么：

- 规则列表。
- 每条规则的结构化描述。
- 规则来源文章。
- 规则是否可进入验证流程。

### Step 3. 回测与画像

作用：

- 用历史市场数据、市场阶段、开盘数据验证规则。
- 判断规则是否可信。
- 沉淀交易员风格画像。

用户能得到什么：

- 规则可信度。
- 规则适用场景。
- 规则失效场景。
- 交易员风格画像。
- 行为特征总结。

### Step 4. 盘前分析

作用：

- 把通过验证的规则、交易员画像和当天市场背景结合起来。
- 生成盘前建议和关注名单。

用户能得到什么：

- 今日盘前重点。
- 候选关注对象。
- 推荐使用的规则。
- 盘前解释和依据。

### Step 5. 盘后复盘

作用：

- 对照盘前判断和盘后市场变化，检查当天结论是否成立。
- 归纳哪些规则有效，哪些规则失效。

用户能得到什么：

- 盘前判断是否命中。
- 规则表现统计。
- 当天复盘结论。
- 对交易员风格的补充修正。

## 5. 页面级导航

建议首页进入后，按下面的方式理解系统：

```text
首页
  ├─ 文章与规则
  │    ├─ 导入文章
  │    ├─ 查看规则抽取
  │    └─ 查看规则详情
  ├─ 回测与画像
  │    ├─ 选择规则
  │    ├─ 查看回测结果
  │    └─ 查看交易员画像
  ├─ 盘前分析
  │    ├─ 查看今日市场上下文
  │    ├─ 查看候选关注对象
  │    └─ 查看盘前建议
  ├─ 盘后复盘
  │    ├─ 查看盘前结论
  │    ├─ 查看盘后市场变化
  │    └─ 查看复盘结论
  └─ 市场上下文
       ├─ 查看当天市场状态
       ├─ 查看结构化背景
       └─ 为回测和复盘提供参照
```

## 6. 页面文案草案

### 6.1 首页

- 标题：规则提取与市场验证工作台
- 副标题：从文章提取规则，验证可信度，并用于盘前与盘后分析

### 6.2 文章与规则页

- 标题：文章与规则
- 说明：导入文章，提取规则，查看结构化结果

常见状态：

- 处理中：文章正在解析
- 成功：已提取规则
- 失败：文章解析失败，请查看原因

### 6.3 回测与画像页

- 标题：回测与画像
- 说明：验证规则可信度，并沉淀交易员风格

常见状态：

- 规则可信：可进入盘前使用
- 规则不稳定：建议继续观察
- 画像稳定：可用于后续筛选

### 6.4 盘前分析页

- 标题：盘前分析
- 说明：结合规则、画像和今天的市场背景生成盘前建议

常见状态：

- 今日建议已生成
- 今日建议为空
- 今日建议需重新计算

### 6.5 盘后复盘页

- 标题：盘后复盘
- 说明：对照盘前判断，检查当天结果，并修正规则理解

常见状态：

- 复盘完成
- 复盘中
- 复盘失败

### 6.6 市场上下文页

- 标题：市场上下文
- 说明：查看当天市场状态、候选对象和结构化背景

常见状态：

- 当前市场状态已加载
- 当前市场上下文为空
- 当前数据尚未完成标准化

## 7. 用户最终能得到什么

用户最终不是得到一堆独立结果，而是得到一条闭环：

1. 哪些文章中的规则被抽取出来了。
2. 这些规则是否可信。
3. 这些规则适合什么市场阶段。
4. 交易员是什么风格。
5. 今天盘前应该关注什么。
6. 盘后判断是否成立。

## 8. 对外叙事建议

建议 Web 对外始终保持同一条主叙事：

> 从文章提取规则 -> 验证规则 -> 形成画像 -> 盘前使用 -> 盘后复盘

不要让用户先理解内部数据结构名词，再去推断业务意义。
