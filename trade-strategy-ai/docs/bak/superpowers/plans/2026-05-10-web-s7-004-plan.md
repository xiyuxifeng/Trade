# WEB-S7-004 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Job Center 增加独立的操作审计表，记录谁在什么时间从什么来源发起了什么操作，以及脱敏后的参数摘要，并在 Job 详情页可见。

**Architecture:** 采用独立审计表 `job_audit_events`，每次 Job 创建和状态变更时由 `JobService` 写入一条审计记录，避免把审计逻辑塞进 Job 主表。`JobService` 负责统一构造审计 payload 和参数摘要，API 路由负责补充请求来源信息，前端 Job 详情页只消费已经结构化好的审计事件列表。

**Tech Stack:** Python/FastAPI, SQLAlchemy, Alembic, React, TanStack Query, Pytest/Vitest

```python
def _sanitize_params(self, params: dict[str, Any] | None) -> dict[str, Any]:
    return ConfigService().mask_config(params or {})

def _record_job_audit(
    self,
    *,
    session: Any,
    job: Job,
    operation: str,
    actor: str,
    source: dict[str, Any],
    payload: dict[str, Any],
    event_at: datetime,
) -> None:
    session.add(
        JobAuditEvent(
            job_id=job.id,
            operation=operation,
            actor=actor,
            source=source.get("channel", "system"),
            params_summary=self._sanitize_params(job.params),
            payload={
                "request_context": source,
                "details": payload,
            },
            event_at=event_at,
        )
    )
```
