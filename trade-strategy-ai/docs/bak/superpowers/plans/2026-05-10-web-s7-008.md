# WEB-S7-008 角色权限模型实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Web 管理后台补齐 `viewer / operator / admin` 最小角色权限模型，后端强制校验权限，前端按角色隐藏或禁用无权限入口，并为本地调试提供默认 API Key。

**Architecture:** 以现有 API Key 作为认证载体，在服务层引入 `principal` 抽象，把 API Key 解析为带角色的身份对象。后端路由通过统一的 `require_role()` 依赖强制校验最小权限，前端通过 `auth/me` 读取当前角色后控制导航、页面按钮和高风险操作。默认 key 只放在默认模板和初始化逻辑中，仓库运行态配置继续保持可覆盖。

**Tech Stack:** FastAPI、Pydantic、React、TanStack Query、Vitest、pytest

from dataclasses import dataclass
from typing import Literal


RoleName = Literal["viewer", "operator", "admin"]
RoleOrder: dict[str, int] = {"anonymous": 0, "viewer": 1, "operator": 2, "admin": 3}


@dataclass(frozen=True)
class Principal:
    role: str
    api_key_label: str | None
    authenticated: bool
    source: str


def _normalize_api_keys(raw_keys: list[object]) -> list[dict[str, str]]:
    normalized: list[dict[str, str]] = []
    for item in raw_keys:
        if isinstance(item, str):
            normalized.append({"key": item, "role": "admin", "label": item})
        elif isinstance(item, dict) and item.get("key"):
            normalized.append(
                {
                    "key": str(item["key"]),
                    "role": str(item.get("role", "admin")),
                    "label": str(item.get("label", item["key"])),
                }
            )
    return normalized
```

export type CurrentPrincipal = {
  role: 'anonymous' | 'viewer' | 'operator' | 'admin';
  authenticated: boolean;
  api_key_label: string | null;
  source: string;
};

export function canAccess(role: CurrentPrincipal['role'], minimum: CurrentPrincipal['role']) {
  const order = { anonymous: 0, viewer: 1, operator: 2, admin: 3 } as const;
  return order[role] >= order[minimum];
}
```
