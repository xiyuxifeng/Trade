# Kaipan 10.5 Ingestion Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `New-Web-Market-Regime-Definition.md` 的 `10.5` Kaipan 接口清单接入现有 Kaipan Web 入口，并让这些标准化后的数据通过现有 `snapshot-build` 流程写入数据库，保持 Web-first、单一事实源和可复现。

**Architecture:** 复用现有 `/kaipan` 抓取入口、`KaipanProvider`、`KaipanService`、`MarketSnapshotService` 和 `MarketDataStorageService`。新增接口先落到 provider 的原始抓取与标准化层，再作为 Market Snapshot 的新增 section 进入现有 `market_snapshots` / `market_snapshot_sections` / `market_snapshot_items` / `market_datasets` / `market_data_quality_reports` 表，不新增 Kaipan 独立业务表。UI 继续使用现有 Kaipan 页面作为入口，只增加 10.5 接口的可见性和触发入口，不新增独立页面。

**Tech Stack:** Python 3.11+, FastAPI, SQLAlchemy async, Pydantic, React, TanStack Query, Vitest, pytest.
