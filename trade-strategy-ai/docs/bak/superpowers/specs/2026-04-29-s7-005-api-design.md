# S7-005 API 查询能力扩展 — 设计方案

> 日期：2026-04-29
> 任务：NTL-S7-005

## 1. 目标

扩展 API 查询能力，支持对策略版本、快照、ranking、回测结果的查询和下载。核心模块已完成，只需暴露 HTTP 接口。

## 2. 架构概览

新增 **4 个 REST Router**，注册到 `api/main.py`：

```
api/
├── main.py              # 已存在，新增路由注册
├── routers/
│   ├── run.py           # 已存在
│   ├── reports.py       # 已存在
│   ├── strategy_versions.py   # 新增
│   ├── snapshots.py           # 新增
│   ├── rankings.py            # 新增
│   └── backtest_results.py    # 新增
```

## 3. 各 Router 端点设计

### 3.1 `strategy_versions.py`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/strategy_versions/` | 列表查询（分页） |
| GET | `/strategy_versions/{version_id}` | 详情（含 rules_snapshot） |
| GET | `/strategy_versions/{version_id}/download` | 下载为 JSON 文件 |

**查询参数**：`trader_id`, `status`(released/draft/candidate), `date_from`, `date_to`, `skip`, `limit`

**数据来源**：DB（`StrategyLibraryRepository`）+ 文件（candidate JSON）

### 3.2 `snapshots.py`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/snapshots/` | 快照列表 |
| GET | `/snapshots/{snapshot_id}` | 快照详情 |
| GET | `/snapshots/{snapshot_id}/download` | 下载为 JSON 文件 |

**查询参数**：`snapshot_type`(hot_topics/topic_constituents/strong_symbols), `date`, `trader_id`, `skip`, `limit`

**数据来源**：`SnapshotService`（文件系统 + JSON index）

### 3.3 `rankings.py`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/rankings/` | 榜单列表 |
| GET | `/rankings/{ranking_id}` | 榜单详情 |
| GET | `/rankings/{ranking_id}/download` | 下载为 JSON 文件 |

**查询参数**：`trader_id`, `date_from`, `date_to`, `skip`, `limit`

**数据来源**：`RankingRepository`（DB）

### 3.4 `backtest_results.py`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/backtest_results/` | 回测结果列表 |
| GET | `/backtest_results/{result_id}` | 回测详情（含 trade_records） |
| GET | `/backtest_results/{result_id}/report` | 回测报告下载 |
| GET | `/backtest_results/{result_id}/validate_rules` | 规则验真报告下载 |

**查询参数**：`trader_id`, `date_from`, `date_to`, `skip`, `limit`

**数据来源**：回测输出 JSON 文件（`data/backtest/results/`）

## 4. 共用设计

### 4.1 分页响应结构

```json
{
  "status": "success",
  "count": 10,
  "total": 100,
  "skip": 0,
  "limit": 50,
  "items": [...]
}
```

### 4.2 下载端点

返回 `FileResponse`（JSON 或 Markdown），提供 Content-Disposition 头触发浏览器下载。

### 4.3 错误处理

| 状态码 | 场景 |
|--------|------|
| 400 | 参数错误（如无效日期格式） |
| 404 | 资源未找到 |
| 500 | 服务器内部错误 |

### 4.4 访问控制

完全开放，无认证。
