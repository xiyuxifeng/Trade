## 1. 目标

扩展 CLI，添加 `snapshot` 和 `strategy` 两个子命令，使关键链路（快照构建、策略版本构建/查询）可直接通过命令行触发。

```
cli/
├── main.py              # 修改：注册 snapshot + strategy 子命令

```

## 3. 子命令设计

### 3.1 `snapshot`（候选池快照）

**命令：** `python -m cli.main snapshot build`

| 参数 | 必选 | 默认值 | 说明 |
|------|------|--------|------|
| `--date` / `-d` | ✅ | — | 交易日期 YYYY-MM-DD |
| `--slot` / `-s` | ❌ | `17-30` | 时段（盘后） |
| `--type` / `-t` | ❌ | `all` | 快照类型：`all`、`hot_topics`、`topic_constituents`、`strong_symbols` |
| `--force` | ❌ | `False` | 强制覆盖已有快照 |

**行为：**
- 默认跳过已存在的快照（`force=True` 时才覆盖）
- slot 已是时效性边界，无需额外 TTL 机制
- 调用已有的 `handle_hot_topics_snapshot` / `handle_topic_constituents_snapshot` / `handle_strong_symbols_snapshot`

**输出示例：**
```
=== 快照构建完成 ===
  date=2026-04-29, slot=17-30
  hot_topics: 12 条，✓ 已保存
  topic_constituents: 8 条，✓ 已保存
  strong_symbols: 20 条，✓ 已保存
```

### 3.2 `strategy`（策略版本）

**命令 1：** `python -m cli.main strategy build`

| 参数 | 必选 | 默认值 | 说明 |
|------|------|--------|------|
| `--trader` / `-t` | ✅ | — | 交易员 ID |
| `--date` / `-d` | ✅ | — | 策略日期 YYYY-MM-DD |
| `--force` | ❌ | `False` | 强制重建（跳过已有发布版本） |

- 输出控制台摘要 + JSON 文件到 `data/processed/strategy_versions/`
- 调用已有的 `handle_build_trader_strategy_version`

**命令 2：** `python -m cli.main strategy list`

| 参数 | 必选 | 默认值 | 说明 |
|------|------|--------|------|
| `--trader` / `-t` | ❌ | — | 限定 trader |
| `--status` / `-s` | ❌ | `all` | 状态过滤：`all`、`released`、`draft`、`candidate` |
| `--limit` / `-l` | ❌ | `50` | 返回数量限制 |

- 从 DB 读取，通过 `StrategyLibraryRepository` 查询
- 分页显示到控制台

## 4. 数据流

### snapshot build

```
CLI snapshot build
  → handle_hot_topics_snapshot(details, config)
    → KaipanProvider.fetch_hot_topics()
    → HotTopicsBuilder.build()
    → SnapshotService.save(MarketUniverse)
```

### strategy build

```
CLI strategy build
  → handle_build_trader_strategy_version(details, config)
    → load_trader_profiles_file()
    → query BlogArticle + ArticleMetadata
    → StrategyLibraryService.build_and_save_draft()
```

## 5. 错误处理

| 场景 | 行为 |
|------|------|
| date 格式错误 | 友好提示 + exit code 1 |
| trader 不存在 | 警告 + 跳过 |
| 快照已存在（非 force） | 跳过 + 提示 "已存在，跳过" |
| kaipan 配置缺失 | 警告 + 跳过该类型 |
| DB 连接失败 | 错误提示 + exit code 1 |

## 6. 注册方式

```python
# cli/main.py
from cli.snapshot import app as snapshot_app
from cli.strategy import app as strategy_app

app.add_typer(snapshot_app, name="snapshot")
app.add_typer(strategy_app, name="strategy")
```

## 7. 验收标准

- `python -m cli.main snapshot --help` 显示 build 子命令
- `python -m cli.main strategy --help` 显示 build + list 子命令
- `snapshot build --date 2026-04-29 --type hot_topics` 成功构建快照
- `strategy list --trader trader_a --status released` 正确过滤
- `strategy build --trader trader_a --date 2026-04-29` 生成 JSON 文件
