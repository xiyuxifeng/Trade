## 通用参数说明

### 请求公共参数

所有接口请求都需要携带以下公共参数：

| 参数名 | 示例值 | 说明 |
|--------|--------|------|
| DeviceID | `4cac82ffc900bae65f51f73b756612a3911b7a7a` | 设备ID |
| PhoneOSNew | `2` | 系统版本 |
| Token | `036ca9cad6e44ee4a585c22cb2c298ed` | 用户Token（可不传） |
| UserID | `3807176` | 用户ID（可不传） |
| VerSion | `5.23.0.1` | 客户端版本 |
| apiv | `w44` | 接口版本 |

### 可选参数

以下参数在大多数接口中不指定的话为可选：
- `Token`
- `UserID`

### 分页参数

| 参数名 | 说明 | 示例 |
|--------|------|------|
| Index | 分页起始索引 | 第一页：0，第二页：20，第三页：40 |
| st | 每页数量 | 通常为 20 |

## 市场概览

### 市场情绪

获取市场情绪指标数据。

**请求方式：** `GET`

**请求URL：** `https://apphis.longhuvip.com/w1/api/index.php`

**请求参数：**

| 参数名 | 必填 | 说明 |
|--------|------|------|
| a | 是 | `ChangeStatistics` |
| c | 是 | `HisHomeDingPan` |
| Date | 是 | 日期，格式：`2026-04-16` |
| st | 是 | 每页数量，如：`1000` |

**请求示例：**
```
Date=2026-04-16&DeviceID=xxx&Index=0&PhoneOSNew=2&Token=xxx&UserID=3807176&VerSion=5.23.0.1&a=ChangeStatistics&apiv=w44&c=HisHomeDingPan&st=1000
```

**响应字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| strong | String | 情绪指标强度 |
| ztjs | String | 涨停家数 |
| lbgd | String | 连板高度 |
| Day | String | 日期 |
| df_num | String | 大幅回撤数量 |

**响应示例：**
```json
{
    "info": [
        {
            "strong": "56",
            "ztjs": "69",
            "lbgd": "7",
            "Day": "2026-04-17",
            "df_num": "3"
        },
        {
            "strong": "68",
            "ztjs": "79",
            "lbgd": "6",
            "Day": "2026-04-16",
            "df_num": "2"
        }
    ],
    "tip": "温馨提示：情绪指标过高（75），短期有释放亏钱效应的风险；情绪指标过低（25），短线有反弹回暖需求",
    "errcode": "0"
}
```

## 涨停分析

### 涨停表现

获取涨停板的整体表现数据，包括晋级率、破板率等。

**请求方式：** `GET`

**请求URL：** `https://apphis.longhuvip.com/w1/api/index.php`

**请求参数：**

| 参数名 | 必填 | 说明 |
|--------|------|------|
| a | 是 | `ZhangTingExpression` |
| c | 是 | `HisHomeDingPan` |
| Day | 是 | 日期，格式：`2026-04-16` |

**响应字段（info 数组）：**

| 索引 | 类型 | 说明 |
|------|------|------|
| [0] | Integer | 涨停家数 |
| [1] | Integer | 2连板家数 |
| [2] | Integer | 3连板家数 |
| [3] | Integer | 最高板数 |
| [4] | Number | 2板晋级率（%） |
| [5] | Number | 3板晋级率（%） |
| [6] | Number | 最高板晋级率（%） |
| [7] | Number | 今日涨停破板率（%） |
| [8] | Number | 昨日涨停表现（%） |
| [9] | Number | 昨日连板表现（%） |
| [10] | Number | 昨日破板表现（%） |
| [11] | String | 总结语 |

**响应示例：**
```json
{
    "info": [71, 5, 1, 2, 10.8696, 12.5, 66.6667, 21.7822, 1.996, 3.034, 1.205, "题材存在炒作机会"],
```
