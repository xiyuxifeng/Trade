- `market-context-and-user-flow.md`

  - 面向 Web 页面落地
  - 说明首页、菜单、页面标题、按钮文案和状态文案

## 统一目标

最终系统必须围绕同一条主链路工作：

```text
博客文章
  -> 规则提取
  -> 回测验证
  -> 交易员画像
  -> 盘前预测
  -> 盘后复盘
```

所有市场数据、候选池、市场状态、快照、Job、页面入口，都必须服务于这条主链路，而不是反过来让用户先学习内部术语。
