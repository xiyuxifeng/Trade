# 每日盘前说明

本文档说明普通用户每天开盘前如何使用 `每日交易` → `今日盘前`。

## 盘前目标

你要在开盘前得到一份可审核的今日计划：

- 今日市场状态。
- 今日启用规则。
- 今日暂停或降级规则。
- 候选标的和信号。
- 入场条件、失效条件、风险提示。
- 是否批准今日计划。

## 操作步骤

1. 进入 `每日交易` → `今日盘前`。
2. 查看盘前数据、历史行情、市场状态、当前正式策略和规则适用性。
3. 如果全部就绪，点击 `生成盘前计划`。
4. 查看今日规则选择、每日策略实例和交易日计划。
5. 选择 `批准今日计划`、`降级使用` 或 `暂停今日计划`。

## 系统会做什么

系统会按以下顺序检查和生成：

```text
数据就绪
→ 市场状态
→ 当前正式策略
→ 规则适用性
→ 今日规则选择
→ 每日策略实例
→ 交易日计划
```

系统不会每天生成新的正式策略。每天生成的是今日运行对象和今日计划。

## 输出结果

盘前完成后，你会看到：

- 今日市场判断。
- 启用规则和原因。
- 暂停规则和原因。
- 候选标的。
- 交易信号。
- 风险提示。
- 计划状态。

## 状态处理

### 正常

含义：

- 必要数据和策略证据都可用。

你应该做什么：

- 审核计划。
- 认可后批准今日计划。

### 部分可用

含义：

- 某些数据或适用性证据不完整。
- 系统只展示可确认的内容。

影响：

- 部分规则可能被降级或暂停。
- 今日计划置信度会下降。

你应该做什么：

- 查看页面给出的影响。
- 能修复时先补齐数据。
- 不能及时修复时，只在你接受风险的情况下选择降级使用。

### 不可用

含义：

- 关键输入缺失，无法生成可信计划。

影响：

- 今日计划不能作为正式依据。

你应该做什么：

- 按页面提示补齐数据或联系管理员。
- 不要把不可用状态当成计划成功。

### 冲突或无效

含义：

- 数据版本、市场状态或策略证据互相不一致。

影响：

- 系统不会自动选择对你有利的结果。

你应该做什么：

- 先处理冲突。
- 等冲突解除后重新生成盘前计划。

## 下一步

交易日结束后，进入 `每日交易` → `今日盘后` 完成复盘。
