# 数据不足和失败处理说明

本文档说明普通用户如何理解系统中的缺失、部分、不可用、降级、无效和冲突状态。

## 基本原则

系统不会把缺失数据当作成功，不会把未知值当作 0，也不会把缺失条件当作满足。

当页面显示异常状态时，请先看三件事：

1. 发生了什么。
2. 影响了什么。
3. 应该怎么处理。

## 常见状态

### 空

含义：

- 当前还没有可展示记录。

影响：

- 可能是还没导入文章、还没生成计划，或当前筛选条件没有结果。

处理：

- 按页面主按钮创建第一条记录。
- 或调整筛选条件。

### 处理中

含义：

- 系统正在处理。

影响：

- 输出尚未固定，不能作为最终结论。

处理：

- 等待处理完成。
- 如果长时间不更新，请联系管理员查看运行状态。

### 部分

含义：

- 只有一部分输入或结果可用。

影响：

- 系统只会使用可确认部分。
- 受影响规则或计划可能降级、暂停或继续观察。

处理：

- 查看缺失范围。
- 能补齐时先补齐。
- 不能补齐时，只在接受影响后继续。

### 不可用

含义：

- 关键输入缺失，不能给出可信结果。

影响：

- 相关计划、复盘、回测或建议不能作为正式依据。

处理：

- 按页面提示补齐数据。
- 如果页面要求管理员处理，请把提示交给管理员。

### 降级

含义：

- 系统可以继续运行，但使用范围或置信度下降。

影响：

- 部分规则暂停。
- 部分结果仅供观察。

处理：

- 阅读降级原因。
- 确认是否接受风险。
- 不接受时停止当前计划，先修复数据。

### 无效

含义：

- 输入不满足业务规则，或数据版本不能互相匹配。

影响：

- 系统不会继续生成正式结果。

处理：

- 按页面提示修改输入。
- 重新生成结果。

### 冲突

含义：

- 多个证据互相矛盾，例如数据版本不一致或策略证据不匹配。

影响：

- 系统无法判断哪个结论可信。

处理：

- 不要手工选择看起来更好的结果。
- 联系管理员检查数据版本、审计记录和恢复状态。

### 无权限

含义：

- 当前账号不能访问该页面或执行该动作。

影响：

- 你无法查看或修改相关内容。

处理：

- 联系管理员调整权限。
- 不要共用高权限账号绕过权限控制。

## 按流程处理

### 文章导入失败

发生了什么：

- 文章内容不完整、重复、格式无法识别，或提取失败。

影响了什么：

- 不会生成可信候选规则。

应该怎么处理：

- 检查标题、作者、发布时间和正文。
- 重新导入或联系管理员查看处理记录。

### 规则不可回测

发生了什么：

- 规则缺少可量化条件、标的范围、时间范围或必要数据。

影响了什么：

- 不能进入正式适用性验证。

应该怎么处理：

- 在审核页面补充或拒绝规则。
- 对无法量化的规则选择继续观察或拒绝。

### 回测样本不足

发生了什么：

- 固定数据版本中的样本量不足。

影响了什么：

- 不能给出强结论。

应该怎么处理：

- 补齐历史行情。
- 扩大可验证范围。
- 或标记为继续观察。

### 盘前计划不可用

发生了什么：

- 盘前数据、市场状态、当前策略或规则适用性缺失。

影响了什么：

- 今日计划不能作为正式依据。

应该怎么处理：

- 先修复缺失项。
- 无法及时修复时，选择暂停或明确降级。

### 盘后复盘不可用

发生了什么：

- 收盘数据、盘前计划或实际结果缺失。

影响了什么：

- 无法可靠判断信号成败。

应该怎么处理：

- 补齐收盘后数据。
- 重新生成复盘。

## 管理员介入

当页面提示需要管理员处理时，普通用户只需要提供：

- 页面名称。
- 显示的状态。
- 发生了什么。
- 影响了什么。
- 页面建议的处理动作。

管理员按 [管理员运维指南](Admin-Operations-Guide.md) 检查配置、数据、运行、权限、备份和审计。
