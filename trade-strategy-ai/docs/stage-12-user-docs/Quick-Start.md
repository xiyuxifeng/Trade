# 快速开始

本文档适合第一次使用 Trade Strategy AI 的普通用户。你只需要按正式导航操作：`首页`、`研究中心`、`规则与回测`、`作者画像`、`策略中心`、`每日交易`。

## 1. 看首页下一步

进入 `首页`。

你要做什么：

- 查看今天数据、盘前计划、盘后复盘、待审核规则和待处理建议。
- 点击首页给出的下一步动作。

系统会做什么：

- 汇总当前数据就绪情况、当前策略、市场状态和待办事项。
- 如果某项不可用，会显示影响和处理动作。

输出结果：

- 今日最需要处理的事项。
- 可直接进入的正式页面。

下一步：

- 如果有文章待导入，进入 `研究中心`。
- 如果有规则待审核，进入 `规则与回测`。
- 如果日常交易已开始，进入 `每日交易`。

## 2. 导入文章并提取规则

进入 `研究中心` → `添加文章`。

你要做什么：

- 粘贴文章内容或填写文章来源。
- 确认作者、标题和发布时间。
- 点击 `导入文章`。

系统会做什么：

- 保存文章版本。
- 用当前提取版本分析文章。
- 区分文章明确声明、系统推断和缺失信息。

输出结果：

- 文章记录。
- 候选规则和证据。
- 需要人工确认的问题。

下一步：

- 进入 `研究中心` → `提取结果` 查看结构化结果。
- 进入 `规则与回测` → `待审核规则` 审核候选规则。

## 3. 审核规则

进入 `规则与回测` → `待审核规则`。

你要做什么：

- 查看每条候选规则的条件、动作、证据和缺失项。
- 对不清楚或证据不足的规则选择继续观察或拒绝。
- 对证据清楚、可以回测的规则选择批准。

系统会做什么：

- 记录审核结论和原因。
- 只把人工批准后的规则纳入正式规则库。
- 不把单纯推断写成事实。

输出结果：

- 正式规则版本。
- 被拒绝或继续观察的规则记录。

下一步：

- 进入 `规则与回测` → `回测实验`。

## 4. 运行回测并查看适用性

进入 `规则与回测` → `回测实验`。

你要做什么：

- 选择已批准规则。
- 选择固定的数据版本和回测范围。
- 点击 `开始回测`。

系统会做什么：

- 使用固定数据版本执行回测。
- 生成全周期结果和分市场状态结果。
- 样本不足时标记样本不足，不给出过强结论。

输出结果：

- 回测结果。
- 数据覆盖情况。
- 规则适用性草稿。

下一步：

- 进入 `规则与回测` → `回测结果`。
- 确认规则适用性后，进入 `作者画像`。

## 5. 查看作者画像

进入 `作者画像`。

你要做什么：

- 查看作者文章方法、规则结构和回测验证三类画像。
- 确认画像结论是否有证据。

系统会做什么：

- 把文章表达、规则统计和回测观察分开展示。
- 不把画像描述成作者真实实盘收益或胜率。

输出结果：

- 作者方法画像。
- 作者规则画像。
- 作者验证画像。

下一步：

- 进入 `策略中心`。

## 6. 发布策略

进入 `策略中心`。

你要做什么：

- 查看策略候选版本。
- 核对规则池、权重、风险设置、作者画像版本和适用性证据。
- 通过验证后发布正式策略。

系统会做什么：

- 检查策略证据是否完整。
- 发布新的正式策略版本。
- 保留回滚和审计记录。

输出结果：

- 当前正式策略版本。
- 策略证据和验证状态。

下一步：

- 每个交易日进入 `每日交易` → `今日盘前`。

## 7. 每日盘前

进入 `每日交易` → `今日盘前`。

你要做什么：

- 检查盘前数据、市场状态、当前正式策略和规则适用性。
- 点击 `生成盘前计划`。
- 审核计划后选择批准、降级使用或暂停。

系统会做什么：

- 生成今日规则选择。
- 生成每日策略实例。
- 生成交易日计划。

输出结果：

- 今日启用和暂停的规则。
- 候选标的、信号、风险提示和失效条件。
- 今日计划状态。

下一步：

- 交易结束后进入 `每日交易` → `今日盘后`。

## 8. 每日盘后

进入 `每日交易` → `今日盘后`。

你要做什么：

- 检查收盘数据是否就绪。
- 点击 `生成盘后复盘`。
- 查看成功、失败、未触发、数据不足和冲突原因。
- 处理规则、画像和策略优化建议。

系统会做什么：

- 对比盘前计划和实际结果。
- 生成结构化归因。
- 分开生成规则优化建议、作者画像修订建议和策略修订建议。

输出结果：

- 盘后复盘。
- 三类优化建议。

下一步：

- 对建议选择接受为草稿、继续观察或拒绝。
- 不用单日结果直接覆盖正式规则、画像或策略。
