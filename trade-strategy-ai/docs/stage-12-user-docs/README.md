# Trade Strategy AI 正式文档入口

本文档入口面向 Stage 12 最终交付后的正式产品路径。普通用户请从“快速开始”和“完整使用手册”开始；管理员和部署者只在需要初始化、维护、升级或排障时阅读对应手册。

## 普通用户文档

- [快速开始](Quick-Start.md)：第一次进入系统时，按最短路径完成文章导入、规则审核、回测、策略发布和每日计划。
- [完整使用手册](User-Manual.md)：按正式导航说明每个页面要做什么、系统会处理什么、输出什么、下一步做什么。
- [每日盘前说明](Daily-Pre-Market-Guide.md)：每天开盘前检查数据、生成计划、批准或降级处理。
- [每日盘后说明](Daily-After-Close-Guide.md)：每天收盘后完成复盘、查看归因、处理优化建议。
- [数据不足和失败处理说明](Data-Failure-Handling.md)：处理缺失、部分、不可用、降级、无效和冲突状态。

## 管理员和部署者文档

- [首次初始化指南](First-Time-Initialization.md)：管理员首次配置系统、初始化数据库、准备基础数据和权限。
- [管理员运维指南](Admin-Operations-Guide.md)：管理员日常维护、备份恢复、迁移、调度、权限、审计和排障。
- [部署与运行手册](Deployment-Runbook.md)：部署者准备运行环境、构建前后端、启动服务、检查健康、升级和回滚。

## 正式产品路径

正式产品路径与 Stage 12 Browser E2E 验收一致：

```text
文章导入
→ 提取规则
→ 审核规则
→ 回测
→ 生成规则适用性
→ 生成作者画像
→ 发布策略
→ 生成盘前计划
→ 完成盘后复盘
→ 生成优化建议
```

普通用户不需要进入旧入口或开发诊断页面。历史链接如果仍被访问，会自动进入对应的正式页面或管理员诊断页面。
