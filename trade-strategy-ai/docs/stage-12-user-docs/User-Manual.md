# 完整使用手册

本文档说明普通用户如何沿正式产品路径使用系统。所有页面都按业务目标组织，不要求理解旧入口或内部运行概念。

## 首页

页面用途：

- 告诉你今天最需要处理什么。
- 汇总今日数据、盘前计划、盘后复盘、当前策略和待处理事项。

当前需要的输入：

- 通常不需要输入。
- 只需要根据首页提示选择下一步。

系统将执行的处理：

- 汇总各业务页面的状态。
- 区分正常、处理中、空、错误、部分、无权限、不可用和降级状态。

输出结果：

- 今日状态。
- 当前策略和市场状态。
- 待审核规则、待处理建议和失败修复入口。

下一步操作：

- 点击首页中的业务动作，例如 `导入文章`、`审核规则`、`开始回测`、`生成盘前计划`、`完成盘后复盘`。

## 研究中心

正式页面：

- `研究中心` → `文章库`
- `研究中心` → `添加文章`
- `研究中心` → `提取结果`

### 添加文章

你要做什么：

- 输入文章标题、作者、来源、发布时间和正文。
- 确认文章内容准确后导入。

系统会做什么：

- 保存文章版本。
- 提取文章结构和候选规则。
- 标记明确证据、系统推断和缺失信息。

会产生什么输出：

- 文章记录。
- 结构化提取结果。
- 候选规则。

下一步应该做什么：

- 到 `提取结果` 查看提取内容。
- 到 `待审核规则` 审核候选规则。

### 文章库

你要做什么：

- 查看已导入文章和处理状态。
- 找到需要继续处理的文章。

系统会做什么：

- 显示每篇文章是否已提取、是否有候选规则、是否需要人工处理。

会产生什么输出：

- 文章列表和处理状态。

下一步应该做什么：

- 对未提取或失败文章重新处理。
- 对已提取文章进入规则审核。

### 提取结果

你要做什么：

- 查看文章结构、规则候选、证据引用和缺失项。

系统会做什么：

- 展示提取结果，不把缺失字段补成成功。

会产生什么输出：

- 可供审核的候选规则。
- 不能回测或需要补充证据的说明。

下一步应该做什么：

- 进入 `规则与回测` → `待审核规则`。

## 规则与回测

正式页面：

- `规则与回测` → `待审核规则`
- `规则与回测` → `正式规则`
- `规则与回测` → `回测实验`
- `规则与回测` → `回测结果`

### 待审核规则

你要做什么：

- 审核候选规则的条件、动作、证据和风险。
- 批准、拒绝或继续观察。

系统会做什么：

- 记录人工审核结论。
- 只把批准后的规则形成正式版本。

会产生什么输出：

- 正式规则版本。
- 被拒绝或观察中的规则。

下一步应该做什么：

- 对正式规则运行回测。

### 正式规则

你要做什么：

- 查看已批准规则、规则版本、规则族和状态。

系统会做什么：

- 展示规则来源、版本和生命周期。

会产生什么输出：

- 可用于回测和策略的规则清单。

下一步应该做什么：

- 选择规则进入 `回测实验`。

### 回测实验

你要做什么：

- 选择规则、数据版本和时间范围。
- 点击 `开始回测`。
- 如果规则数量较多，切换到 `规则池批量回测`，按筛选条件多选已通过规则，设置每批规则数后创建批次计划。

系统会做什么：

- 使用固定数据版本执行回测。
- 不在回测过程中读取实时数据。
- 生成全周期和分市场状态结果。
- 批量回测时，系统只生成可控的小批次；每个批次需要你手动启动，可以手动暂停当前批次后再继续。

会产生什么输出：

- 回测结果。
- 数据覆盖和样本状态。
- 规则适用性草稿。
- 批量回测的批次计划、每批运行状态和合并后的规则池结果。

下一步应该做什么：

- 到 `回测结果` 查看并确认。
- 批量回测时，确认所有批次完成后点击 `合并批次结果`，再进入 `回测结果` 查看合并结果。

### 回测结果

你要做什么：

- 查看收益、回撤、样本量、分市场状态结果和数据限制。
- 对样本不足或数据缺失的结果保持观察。
- 如果来自规则池批量回测，查看合并摘要和每条规则的批次来源。

系统会做什么：

- 展示结果和证据版本。
- 对样本不足、不可用和冲突状态给出影响和处理建议。
- 对批量结果保留每条规则来自哪个批次和哪次运行记录，参数不一致、批次失败或缺少结果时不会伪装成成功。

会产生什么输出：

- 可确认的规则适用性。
- 需要补数据或继续观察的规则。
- 合并后的规则池回测结果。

下一步应该做什么：

- 确认适用性后进入作者画像或策略中心。

## 作者画像

页面用途：

- 展示作者文章方法、规则结构和回测验证结果。

当前需要的输入：

- 通常不需要手工输入。
- 需要时选择作者或画像版本。

系统将执行的处理：

- 汇总文章表达、规则统计和回测观察。
- 新证据只生成草稿或修订建议。

输出结果：

- 作者方法画像。
- 作者规则画像。
- 作者验证画像。

下一步操作：

- 使用已发布画像作为策略证据。
- 对新画像草稿进行审核，不直接覆盖正式画像。

## 策略中心

正式页面：

- `策略中心`
- `策略中心` → `候选版本`

页面用途：

- 管理正式策略版本、验证结果、发布和回滚。

当前需要的输入：

- 已审核规则。
- 规则适用性。
- 作者画像版本。
- 风险设置和标的范围。

系统将执行的处理：

- 生成或展示策略候选版本。
- 校验策略证据是否完整。
- 发布或回滚正式策略。

输出结果：

- 当前正式策略版本。
- 候选策略和验证状态。
- 版本差异和回滚记录。

下一步操作：

- 发布通过验证的策略。
- 进入每日盘前使用当前正式策略。

## 每日交易

正式页面：

- `每日交易` → `今日总览`
- `每日交易` → `今日盘前`
- `每日交易` → `今日盘后`

### 今日总览

你要做什么：

- 查看今天盘前和盘后的完成情况。

系统会做什么：

- 汇总今日数据、计划、复盘和建议状态。

会产生什么输出：

- 今日处理进度和下一步动作。

下一步应该做什么：

- 盘前进入 `今日盘前`。
- 收盘后进入 `今日盘后`。

### 今日盘前

你要做什么：

- 检查数据就绪状态。
- 生成并审核今日计划。

系统会做什么：

- 判断市场状态。
- 选择今日适用规则。
- 生成每日策略实例和交易日计划。

会产生什么输出：

- 今日启用规则、暂停规则、候选标的、信号和风险提示。

下一步应该做什么：

- 批准计划、降级使用或暂停交易。

### 今日盘后

你要做什么：

- 生成复盘。
- 查看归因和优化建议。

系统会做什么：

- 对比计划与实际结果。
- 生成结构化归因。
- 分开生成规则、画像和策略建议。

会产生什么输出：

- 盘后复盘。
- 优化建议。

下一步应该做什么：

- 接受为草稿、继续观察或拒绝建议。

## 系统管理

普通用户一般不需要进入系统管理。管理员会在这里处理配置、数据、运行、审计、健康、备份和权限。

如果业务页面提示需要管理员处理：

- 普通用户应把页面显示的影响和建议交给管理员。
- 管理员按 [管理员运维指南](Admin-Operations-Guide.md) 处理。
