### 规则映射表

```python
RULE_ADJUSTMENT_TYPE_MAP = {
    # 命中率极低 + 后验收益负 → 删除规则
    "hit_rate_too_low_and_return_negative": "delete_rule",
    # 命中率高但收益负 → 复核止盈止损（修改 action 参数）
    "high_hit_rate_but_negative_return": "review_stop_loss",
    # 规则未命中但收益正 → 升级程序化
    "missed_opportunity": "upgrade_rule",
    # 快照缺失 → 保留原规则，新增 note
    "missing_snapshot": "check_snapshot",
    # 程序化但命中率极低 → 修改条件
    "programmable_but_rarely_hit": "delete_rule",
}
```

### rules_snapshot 修改规则

| RuleAdjustment.current_status | rules_snapshot 操作 |
|---|---|
| `hit_rate_too_low_and_return_negative` | 删除 rule_id 对应的规则 |
| `high_hit_rate_but_negative_return` | 保留 rule_id，修改 action（收紧止盈/止损参数） |
| `missed_opportunity` | 保留 rule_id，标记 programmable=True |
| `missing_snapshot` | 保留 rule_id，不修改，附加 note |
| `programmable_but_rarely_hit` | 保留 rule_id，修改 condition（放宽条件） |
