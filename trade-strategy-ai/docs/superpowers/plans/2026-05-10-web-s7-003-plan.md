# WEB-S7-003 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为高风险 Workflow/Job 增加后端强校验和前端确认提交闭环，确保未确认的高风险任务不能创建。

**Architecture:** 在 `WorkflowService` 内集中判断工作流是否需要二次确认，并把确认结果作为运行请求的一部分显式传递到后端校验。前端继续复用现有确认弹窗，但提交时必须携带确认标记。这样 UI 负责引导，服务端负责最终拦截，避免只做前端提示。

**Tech Stack:** Python/FastAPI, Pydantic, React, TanStack Query, Vitest/Pytest

```python
async def run_workflow(
    self,
    *,
    workflow_id: str,
    params: dict[str, Any] | None = None,
    created_by: str | None = None,
    idempotency_key: str | None = None,
    confirmed: bool = False,
) -> ServiceResult:
    workflow = _WORKFLOW_MAP.get(workflow_id)
    if workflow is None:
        return ServiceResult(status="partial", message="workflow not found", payload={"workflow_id": workflow_id})
    requires_confirmation = workflow.job_definition.requires_confirmation if workflow.job_definition else any(
        step.requires_confirmation for step in workflow.steps
    )
    if requires_confirmation and not confirmed:
        return ServiceResult(
            status="error",
            message="confirmation required for high-risk workflow",
            payload={"workflow_id": workflow_id, "requires_confirmation": True},
        )
```
