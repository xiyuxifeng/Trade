## 二、S7-001 活跃 trader 筛选（ActiveTraderFilter）

### 2.1 核心算法

**公式：贝叶斯收缩（Bayesian Shrinkage）**

```python
# 1. 胜率收缩（向 baseline_win_rate = 0.5 收缩）
# alpha=10 表示"10 笔先验交易"的权重
adjusted_win_rate = (wins + alpha * baseline_win_rate) / (valid_trades + alpha)

# 2. 交易数置信度因子（样本不足时折扣）
# 低于 min_trades 时降低权重，避免样本过少时胜率被噪声主导
sample_confidence = min(valid_trades / min_trades, 1.0)

# 3. 综合得分
score = adjusted_win_rate * sample_confidence
```

**为什么这样设计：**

- 交易数 < `min_trades` 时，`sample_confidence < 1`，直接折扣得分
- `alpha=10` 让少于 10 笔交易的 trader 向 50% baseline 收缩
- 10 笔以上基本不变，原始胜率被保留
- 结果天然可解释："考虑了样本量后的有效胜率"

### 2.2 配置项（config.py）

```python
@dataclass
class ActiveTraderFilterConfig:
    """活跃 trader 筛选配置。"""
    min_win_rate: float = 0.40      # 最低原始胜率门槛（含）
    min_trades: int = 10           # 最小有效交易笔数（含）
    bayesian_alpha: float = 10.0   # 贝叶斯收缩强度（越大收缩越强）
    baseline_win_rate: float = 0.50 # 先验基准胜率

    # 规则命中率阈值（用于过滤规则质量）
    min_rule_hit_rate: float | None = None  # None 表示不检查

    # 综合得分门槛
    min_score: float = 0.30        # 最终得分门槛（含）
```

### 2.3 接口

```python
@dataclass
class TraderFilterResult:
    """单个 trader 的筛选结果。"""
    trader_id: str
    filter_passed: bool
    raw_win_rate: float | None          # 原始胜率（未收缩）
    adjusted_win_rate: float | None    # 贝叶斯收缩后胜率
    valid_trades: int                  # 有效交易笔数
    sample_confidence: float            # 样本置信度（0~1）
    composite_score: float              # 综合得分
    pass_reasons: list[str]            # 通过原因列表
    fail_reasons: list[str]            # 未通过原因列表
    rule_quality: dict[str, float]     # 规则质量：rule_id -> hit_rate


class ActiveTraderFilter:
    def filter(
        self,
        backtest_results: dict[str, BacktestResult],
        rankings: dict[str, list[RankingEntry]] | None = None,
        rule_validations: dict[str, list[RuleValidationResult]] | None = None,
    ) -> list[TraderFilterResult]:
        """对多个 trader 执行筛选。

        Args:
            backtest_results: {trader_id: BacktestResult}
            rankings: 可选，{trader_id: [RankingEntry]}，用于参考近期 ranking
            rule_validations: 可选，{trader_id: [RuleValidationResult]}，用于规则质量过滤

        Returns:
            通过筛选的 TraderFilterResult 列表（按 composite_score 降序）
        """
```

### 2.4 筛选流程

```
输入: BacktestResult[] + RankingEntry[] + RuleValidationResult[]（可选）
  │
  ▼
┌─────────────────────────────────────────────────────────────┐
│ 1. 校验 BacktestResult.summary                               │
│    - valid_trades >= min_trades                             │
│    - raw_win_rate >= min_win_rate                           │
└─────────────────────────────────────────────────────────────┘
  │
  ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. 计算贝叶斯收缩胜率 + 置信度因子 + 综合得分                  │
│    adjusted_win_rate = (wins + alpha * baseline) / (n + alpha) │
│    sample_confidence = min(n / min_trades, 1.0)               │
│    composite_score = adjusted_win_rate * sample_confidence    │
└─────────────────────────────────────────────────────────────┘
  │
  ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. 可选：检查规则命中率（min_rule_hit_rate）                  │
│    - 任一规则的 hit_rate < 门槛 → 标记 fail_reasons          │
│    - hit_rate 高的规则 → pass_reasons                        │
└─────────────────────────────────────────────────────────────┘
  │
  ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. 最终判断: filter_passed = composite_score >= min_score      │
└─────────────────────────────────────────────────────────────┘
  │
  ▼
输出: list[TraderFilterResult]（按 composite_score 降序）
```

### 2.5 筛选维度总结

| 维度 | 参数 | 说明 |
|------|------|------|
| 最低原始胜率 | `min_win_rate=0.40` | raw_win_rate >= 门槛 |
| 最小交易笔数 | `min_trades=10` | valid_trades >= 门槛 |
| 贝叶斯收缩 | `bayesian_alpha=10` | 向 baseline=0.5 收缩 |
| 综合得分门槛 | `min_score=0.30` | composite_score >= 门槛 |
| 规则质量（可选） | `min_rule_hit_rate` | 任一规则命中率低于门槛则不选 |

## 三、S7-002 策略调整建议（StrategyAdvisor）

### 3.1 调整建议生成规则

ADJUSTMENT_RULES = [
    # 规则1：命中率极低 + 后验收益负 → 建议删除

        "condition": lambda r: (
            r.hit_rate is not None and r.hit_rate < 0.10
            and r.posterior_return_mean is not None

        "current_status": "hit_rate_too_low_and_return_negative",

    },
    # 规则2：命中率高但收益负 → 建议复核止盈止损
    {

                      "但后验收益 {return_mean:.2%}，可能是止盈过紧或止损过宽。",
    },
    # 规则3：规则未命中但后验收益为正 → 建议升级为程序化
    {

        "suggestion": "规则未充分触发（命中率 {hit_rate:.0%}），"

### 3.2 接口

```python
@dataclass
class RuleAdjustment:
    """单条规则调整建议（S7-002 输出）"""
    trader_id: str
    rule_id: str
    rule_text: str
    current_status: str           # 如 "hit_rate_too_low_and_return_negative"
    suggestion: str               # 调整建议文本
    confidence: float             # 建议置信度 0-1
    hit_rate: float | None
    posterior_return_mean: float | None
    posterior_return_median: float | None


@dataclass
class AdvisorResult:
    """S7-002 完整输出"""
    trader_id: str
    trade_date: str | None        # 规则验真的交易日期
    adjustments: list[RuleAdjustment]
    skipped_rules: list[str]       # 跳过检查的 rule_id（不满足任何 condition）


class StrategyAdvisor:
    def advise(
        self,
        rule_validations: list[RuleValidationResult],
        backtest_summary: BacktestSummary | None = None,
    ) -> list[RuleAdjustment]:
        """基于规则验真结果生成策略调整建议。

        Args:
            rule_validations: 单个 trader 的规则验真结果列表
            backtest_summary: 可选，回测汇总（用于辅助判断）

        Returns:
            list[RuleAdjustment] — 所有匹配 condition 的调整建议
        """
```

### 3.3 与 StrategyAdjustment 的关系

- `RuleAdjustment`（S7-002 输出）经过滚动窗口稳定性验证后，映射为 `StrategyAdjustment`（已在 `src/strategy_library/schemas.py` 定义）
- S7-002 直接输出 `RuleAdjustment`，由 S7-004 滚动窗口决定是否真正触发调整
